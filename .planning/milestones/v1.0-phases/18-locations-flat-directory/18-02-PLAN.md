### Task 1: Update load_orbit_map() for self-registration

In `data_loader.py`, after loading the base orbit map YAML (permanent moons only), merge location entries:

```python
def load_orbit_map(self, system_slug, body_slug):
    # ... existing code to load orbit_map.yaml ...
    orbit_data = yaml.safe_load(f) or {}
    
    # Inject locations that orbit/surface this body
    all_locations = self.load_all_locations()
    orbital_stations = []
    surface_markers = []
    
    for loc in all_locations:
        if loc.get('body_slug') != body_slug:
            continue
        orbital_block = loc.get('orbital', {})
        if not orbital_block:
            continue
        
        parent_type = loc.get('parent_type', 'orbit')
        entry = {
            'slug': loc['slug'],
            'name': loc.get('name', loc['slug']),
            **orbital_block,
        }
        if parent_type == 'orbit':
            orbital_stations.append(entry)
        elif parent_type == 'surface':
            surface_markers.append(entry)
    
    orbit_data['orbital_stations'] = orbital_stations
    orbit_data['surface_markers'] = surface_markers
    return orbit_data
```

### Task 3: Update get_location_path() for flat locations

`get_location_path()` currently builds a breadcrumb path by traversing the filesystem. For flat locations, reconstruct the path from fields:

```python
def get_location_path(self, slug):
    """Return breadcrumb path list for a location slug.
    
    For flat locations (data/locations/): [system_slug, body_slug, slug]
    For celestial bodies (data/galaxy/): retain existing tree traversal.
    """
    # Check data/locations/ first
    loc_dir = self.data_dir / 'locations' / slug
    if loc_dir.exists():
        loc_yaml = loc_dir / 'location.yaml'
        if loc_yaml.exists():
            with open(loc_yaml) as f:
                loc = yaml.safe_load(f) or {}
            system_slug = loc.get('system_slug', '')
            body_slug = loc.get('body_slug', '')
            return [s for s in [system_slug, body_slug, slug] if s]
    
    # Fall back to galaxy tree traversal for celestial bodies
    return self._get_celestial_path(slug)
```

# Phase 18-01: Locations Flat Directory — Data Migration + Backend

## Goal

Move all non-celestial locations (stations, bases, derelict ships, NPC vessels) from their nested positions inside `data/galaxy/` into a flat `data/locations/{slug}/` directory. Each location becomes self-describing with explicit `parent_type`, `body_slug`, and `system_slug` fields — no more implicit context from directory nesting.

## Pre-requisite: Git safety tag

**Before executing this plan, create a git tag:**
```bash
git tag pre-location-restructure
```

Phase 18 is destructive — files move and will eventually be removed from `data/galaxy/`. The only clean recovery path is git. Do not proceed without this safety net.

## Context

Current locations buried in galaxy tree (must identify all before migrating):
```bash
find data/galaxy/ -name "location.yaml" | grep -v "^data/galaxy/[^/]*/location.yaml$" | grep -v "^data/galaxy/[^/]*/[^/]*/location.yaml$"
```

This finds location.yaml files more than 2 levels deep (i.e., facilities, not systems or planets).

For each found location, determine:
- `parent_type`: orbit | surface | dock | deep_space
- `body_slug`: the celestial body it orbits/sits on (must match a `data/galaxy/` dir name exactly)
- `system_slug`: the star system (must match a `data/galaxy/` top-level dir name exactly)
- `orbital:` block data (from the `orbital_stations:` entry in the parent `orbit_map.yaml`)

### Task 3: Update load_all_locations() in DataLoader

Replace the current recursive galaxy tree traversal with a flat scan of `data/locations/`:

```python
def load_all_locations(self):
    """Load all visitable locations from data/locations/.
    
    Each location is a directory containing location.yaml.
    Returns list of location dicts with 'slug' and 'directory' keys added.
    """
    locations_dir = self.data_dir / 'locations'
    if not locations_dir.exists():
        return []
    
    locations = []
    for location_dir in sorted(locations_dir.iterdir()):
        if not location_dir.is_dir():
            continue
        if location_dir.name.startswith(('.', '__')):
            continue
        location_yaml = location_dir / 'location.yaml'
        if not location_yaml.exists():
            continue
        
        with open(location_yaml) as f:
            loc = yaml.safe_load(f) or {}
        
        loc['slug'] = location_dir.name
        loc['directory'] = str(location_dir)
        locations.append(loc)
    
    return locations
```

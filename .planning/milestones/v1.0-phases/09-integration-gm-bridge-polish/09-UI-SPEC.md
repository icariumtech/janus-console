## Layout Contracts

### BridgeView Main Dashboard

```
gm-bridge-view (position: relative, display: flex, flex-direction: row, flex: 1)
├── gm-bridge-view__main (flex: 1, display: flex, flex-direction: column, min-width: 0)
│   ├── gm-bridge-breadcrumb (height: 36px, flex-shrink: 0, display: flex, align-items: center)
│   └── gm-bridge-content (flex: 1, display: flex, flex-direction: row, min-height: 0)
│       ├── gm-bridge-map-panel (flex: 1, position: relative, min-width: 0)
│       └── gm-bridge-status-panel (width: 360px, flex-shrink: 0, overflow-y: auto)
└── gm-bridge-view__right (pre-existing, width: 48px) — ToolRail only after ship-status removal
```

CSS approach: flex column for `__main`, flex row for `gm-bridge-content`. No grid. Width of `gm-bridge-status-panel` is fixed at 360px — not percentage-based — so the map always gets the remaining space.

### Breadcrumb Content Rules

| Player state | Breadcrumb text |
|-------------|-----------------|
| `view_type === 'BRIDGE'`, `bridge_tab === 'map'`, `view_slug` set | `MAP > {DISPLAY_NAME}` (look up display name from locations tree; fall back to slug) |
| `view_type === 'BRIDGE'`, `bridge_tab === 'map'`, no `view_slug` | `MAP` |
| `view_type === 'BRIDGE'`, `bridge_tab` is anything else | `{BRIDGE_TAB.toUpperCase()}` |
| `view_type !== 'BRIDGE'` | `BRIDGE — PLAYER ON {view_type}` |
| `activeView` null | `BRIDGE` |

Breadcrumb separator: ` > ` (space-chevron-space), no icon.

### Map Panel Behavior

| Player state | Map panel shows |
|-------------|-----------------|
| `bridge_tab === 'map'`, `view_slug` matches a system | `GalaxyMap` or `SystemMap` (derive from locations tree depth) |
| `bridge_tab === 'map'`, no slug (galaxy level) | `GalaxyMap` |
| `bridge_tab !== 'map'` | Placeholder: monospace text `PLAYER VIEWING: {bridge_tab.toUpperCase()}`, centered, color `var(--color-text-muted)` |
| `view_type !== 'BRIDGE'` | Placeholder: `PLAYER NOT ON BRIDGE`, centered, color `var(--color-text-muted)` |

R3F map components: mount via `display: none` toggle when not in map tab (preserves WebGL context). Do not unmount/remount on tab switch.

## Interaction Contracts

### NPC Portrait Tooltip

- **Trigger**: Mouse hover over NPC name `<Text>` in NpcPortraitsPanel
- **Delay**: Ant Design default (100ms) — do not override
- **Placement**: `"left"` (tooltip appears to the left of the panel column)
- **Image size**: 120px wide × 160px tall, `object-fit: cover`
- **Container style**: `overlayInnerStyle={{ padding: 4, background: '#0a0f0f', border: '1px solid #4a6b6b' }}`
- **Fallback**: When `npc.portrait` is falsy (empty string or undefined), tooltip title is plain string `'No portrait available'`
- **Cursor**: `cursor: 'default'` on the `<Text>` — not pointer (it's not a click target)

### SessionDetailView Markdown

- **Container**: `<div className="gm-session-markdown">` inside existing Ant Design `<Modal>` body
- **Libraries**: `ReactMarkdown` with `[remarkGfm]` plugin array — identical to player `LogsSection.tsx`
- **Custom components**: `h1`, `h2`, `h3`, `p`, `strong`, `code` — mapped to `gm-md-*` CSS classes
- **Empty state**: When `session.body` is falsy, render `<Text type="secondary" style={{ fontSize: 12 }}>No content.</Text>`
- **Scrolling**: Modal handles scroll — `gm-session-markdown` itself has no `overflow` constraint

### Ship Status SSE

- **SSE event name**: `shipstatus` (named event, not anonymous `message`)
- **Event payload shape**: Fully-merged `ShipStatusData` object (YAML defaults + overrides applied) — not the raw overrides dict
- **Initial state**: Loaded from `window.INITIAL_DATA.shipStatus` on mount; SSE updates replace it entirely (no merge needed if payload is already merged)
- **Update path**: `GMConsole.tsx` `useSSE` → `onShipStatusEvent` callback → `setShipData(newData)` → `shipData` prop passed to `BridgeView` → passed to `GmBridgeStatusPanel` (which replaces `ShipStatusToolPanel`)
- **Flicker animation**: Existing `changingFlags` logic in StatusSection compares previous vs new — preserve this behavior; compare refs when driven by SSE
- **Connection error**: Pre-existing `SSEConnectionToast` handles reconnect — no new UI needed

### BridgeView Map Mirror

- **Navigation**: Read-only — GM cannot click stars/systems in the mirror. Disable all `onClick` / `onSelect` handlers when rendering in GM context, or pass a no-op function
- **R3F context preservation**: Use `display: none` (not conditional rendering) to hide map when not in map tab
- **Driven by**: `activeView.view_slug` + `activeView.bridge_tab` — no independent GM navigation state

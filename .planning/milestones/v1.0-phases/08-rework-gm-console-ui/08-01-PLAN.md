  <action>
Rewrite `GMConsole.tsx` to use the new layout architecture. Keep ALL existing state management, SSE subscription, API callbacks, and data loading logic intact. The change is purely structural -- replacing the render tree.

**Remove:**
- `import { Layout, Tabs }` from antd (keep `message`, `ConfigProvider`, `theme`).
- `const { Content, Sider } = Layout` destructure.
- The entire `<Layout>` / `<Sider>` / `<Content>` / `<Tabs>` render tree.
- `import { BroadcastForm }` and `handleBroadcast` callback (BROADCAST removed per user decision).
- `import { ViewControls }` (replaced by ViewRail).

**Add:**
- `import { ViewRail, GMViewType } from '@/components/gm/layout/ViewRail'`.
- `const [gmView, setGmView] = useState<GMViewType>('STANDBY')` -- purely local state, NOT tied to `activeView.view_type`.
- `GMConsole.css` import for top-level layout styles.
- `handleDisplay` callback: pushes current `gmView` to player terminal by calling the appropriate API:
  - `gmView === 'STANDBY'` -> `gmConsoleApi.switchToStandby()`
  - `gmView === 'BRIDGE'` -> `gmConsoleApi.switchToBridge()`
  - `gmView === 'ENCOUNTER'` -> `gmConsoleApi.switchView('ENCOUNTER', activeView?.location_slug || '')`
  - `gmView === 'CHARON'` -> `charonApi.switchToCharon()`
- Update `activeCharonChannel` derivation to use `gmView` instead of `activeView?.view_type` (CHARON channel follows GM's local view, not player view).

**New render tree:**
```
<div className="gm-console">
  <SSEConnectionToast /> (if connectionLost)
  {contextHolder}
  <ViewRail
    gmView={gmView}
    playerView={activeView?.view_type || 'STANDBY'}
    onViewChange={setGmView}
    onDisplay={handleDisplay}
  />
  <main className="gm-console__content">
    {gmView === 'STANDBY' && <div className="gm-console__placeholder">STANDBY</div>}
    {gmView === 'BRIDGE' && <div className="gm-console__placeholder">BRIDGE VIEW (Plan 03)</div>}
    {gmView === 'ENCOUNTER' && <div className="gm-console__placeholder">ENCOUNTER VIEW (Plan 02)</div>}
    {gmView === 'CHARON' && <div className="gm-console__placeholder">CHARON VIEW (Plan 03)</div>}
  </main>
</div>
```

Placeholder divs will be replaced by real view components in Plans 02 and 03. For now they just show the view name so the layout can be tested.

# Phase 16-01: Ship Data Consolidation

## Goal

Consolidate the USCSS Morrigan's data from 4 files into 2:
- `data/campaign/ship/ship.yaml` — identity, status, systems, resources (moved from root-level `ship.yaml`)
- `data/campaign/ship/deckplan.yaml` — deck map (merged from `map/main_deck.yaml`)

Delete the now-redundant `ship/location.yaml` and `ship/map/manifest.yaml`.

## Pre-requisite

**Merge the Phase 14 branch (`feature/bridge-status-ship-systems`) before executing this plan.**
Phase 14 added reactor system + resource fields to `data/campaign/ship.yaml`. This plan moves that file. If Phase 14 is not merged first, the path change will apply to the pre-reactor YAML and lose those additions.

Current state (4 files, 3 copies of "USCSS Morrigan"):

- `data/campaign/ship/location.yaml` — 3 lines: name, type, description (duplicate of ship.yaml)
- `data/campaign/ship/map/manifest.yaml` — deck list + ship name (duplicate)
- `data/campaign/ship/map/main_deck.yaml` — actual grid map data

Target state (2 files):
- `data/campaign/ship/ship.yaml` — everything from current ship.yaml (structure unchanged)
- `data/campaign/ship/deckplan.yaml` — deck data in `decks:` list format

New format:
```yaml

# All decks for USCSS Morrigan. Add entries under decks: for additional levels.

hull:
  polygon:
    # ... copy hull polygon points from main_deck.yaml (or manifest.yaml if stored there)

    default: true

```

The `hull:` block moves to the top level (applies to all decks). The original deck data becomes the first (and only) entry in the `decks:` list.

### Task 5: Add load_deckplan() method

Add a new method to `DataLoader`:

```python
def load_deckplan(self, location_dir):
    """Load deckplan.yaml from a location directory.
    
    Returns dict with keys:
      - decks: list of deck dicts sorted by level (ascending)
      - hull: top-level hull dict (or None if not present)
      - total_decks: len(decks)
    
    Replaces load_encounter_manifest() for locations using the new deckplan format.
    """
    deckplan_path = Path(location_dir) / 'deckplan.yaml'
    if not deckplan_path.exists():
        return {'decks': [], 'hull': None, 'total_decks': 0}
    
    with open(deckplan_path) as f:
        data = yaml.safe_load(f)
    
    decks = data.get('decks', [])
    decks_sorted = sorted(decks, key=lambda d: d.get('level', 0))
    hull = data.get('hull', None)
    
    return {
        'decks': decks_sorted,
        'hull': hull,
        'total_decks': len(decks_sorted),
    }
```

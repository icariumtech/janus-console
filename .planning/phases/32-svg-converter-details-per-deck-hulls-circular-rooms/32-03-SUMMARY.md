# Phase 32 Plan 03: SVG Converter Details Layer Summary

**`svg_to_map.py` gains `_extract_details_layer()` — a per-deck "Details" sublayer parser emitting decorative polyline/circle linework entries with room-association-based interior/exterior gating, closing out DET-02 and the whole Phase 32 SVG-converter gate.**

## Accomplishments
- `_extract_details_layer(parent, unit, tx, ty, all_areas)` — new function mirroring `_extract_vents_layer`'s id-derivation (`detail_{i+1}` fallback), warn-and-skip (<2-vertex), and print conventions.
- Closed/open detection reads the raw `d` attribute string directly (`d.rstrip().endswith(("Z","z"))`), never `parse_path_d()`'s return value — sidesteps the dedup-logic ambiguity (Pattern 4/Pitfall 3) and requires zero signature change to `parse_path_d()` or its five other existing callers.
- Room association reuses `_find_room_at()`/`_point_in_polygon()` completely unchanged, probing the detail's first vertex (polylines) or center (circles) as its authored position — no new containment algorithm.
- Circle details reuse Plan 01's `_extract_circle_shape()`/`_get_circle_shape_elements()` exactly, continuing the same id-numbering sequence as the polyline loop to avoid collisions.
- `convert()`'s multi-deck loop gains a `_extract_details_layer()` call, storing the result on `decks_data[i]["details"]` — scoped to multi-deck mode only, matching Plan 02's per-deck-Hull precedent (no per-deck `<g>` exists in single-deck mode).
- `_write_deckplan_yaml()` gains a `details:` emission block immediately after the existing `vents:` block — `points:`/`circle:` are mutually exclusive per entry, `closed:`/`filled:` only written for closed polylines.
- `docs/schemas/schema-encounters.md`'s Tooling Note gains a `Details` per-deck sublayer bullet plus two sentences resolving both Claude's-Discretion items: the authored-position tie-break rule and the auto-generated-id convention.
- `tools/test_svg_to_map.py` — `DetailsTests` (new, stdlib `unittest`), 6 tests, all passing.
- Phase-gate regression: full 19-test suite (`CircleRoomTests` + `HullTests` + `DetailsTests`) green together; both existing fixture SVGs (`ship_template.svg`, `ship_template_multideck.svg`) re-converted with zero output change — no `details:`, per-deck `hull:`, or `circle:` keys introduced.

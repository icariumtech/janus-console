<objective>
Extend `tools/svg_to_map.py` so a per-deck `"Hull"` sublayer (nested inside each deck's `<g>`,
sibling to `Rooms`/`Corridors`/`Doors`/`Vents`) produces a per-deck hull polygon set —
including multi-polygon hulls (pods, nacelles, detached modules) — in the output
`deckplan.yaml`. This requires refactoring the root-level Hull parsing to also collect ALL
`<path>` elements and holes (D-02), via one shared extraction function used by both the
top-level and per-deck hull.

Purpose: HULL-03 is the converter-side counterpart of Phase 31's renderer-side additive-merge
hull design (`mergeHulls(shared, deck)`) — the schema already supports `polygons:`/`holes:`
(top-level and per-deck); this plan makes the converter emit it.
Output: `_extract_hull_layer()` (shared multi-path+holes extractor), `_write_hull_block()`
(shared YAML emitter), refactored `hull_data` threading through `convert()` and
`_write_deckplan_yaml()`, per-deck `hull:` emission, schema doc update.
</objective>

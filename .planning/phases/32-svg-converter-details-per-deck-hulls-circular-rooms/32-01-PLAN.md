<objective>
Extend `tools/svg_to_map.py` so `<circle>`/`<ellipse>` SVG elements — both literal elements
and Inkscape's native `sodipodi:type="arc"` path serialization — inside a `Rooms` or
`Corridors` layer produce `circle: {cx, cy, r}` room/corridor entries in the output
`deckplan.yaml`. A non-circular ellipse (rx != ry) is rejected with a stderr warning, never
approximated (D-06).

Purpose: CIRC-01 is the last unimplemented leg of the circular-rooms feature — the renderer
(`RoomsLayer.tsx`) already draws `room.circle` today; this plan is purely "generate the YAML
the renderer already reads."
Output: `get_layer_shapes()` (generalized layer lookup), `_extract_circle_shape()` +
`_get_circle_shape_elements()` (circle/ellipse/sodipodi-arc detection), `circle:` YAML
emission, `tools/test_svg_to_map.py` (new test file, `CircleRoomTests`), schema doc update.
</objective>

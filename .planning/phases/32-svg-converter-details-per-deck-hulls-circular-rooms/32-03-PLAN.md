<objective>
Extend `tools/svg_to_map.py` so a per-deck `"Details"` sublayer (nested inside each deck's
`<g>`, same nesting convention as `Hull`/`Vents`) produces decorative detail linework entries
in the output `deckplan.yaml` — polylines or circles, each associated with its containing room
(interior, reveal-gated) or left unassociated (exterior, always visible) via geometric
containment.

schema (`details:` field) and the renderer (reveal-gating via room-group mounting) already
shipped in Phase 31; this plan makes the converter emit the field.
Output: `_extract_details_layer()`, `details:` YAML emission, wired into `convert()`'s
multi-deck loop, schema doc update, and the phase-gate full-suite regression check.
</objective>
